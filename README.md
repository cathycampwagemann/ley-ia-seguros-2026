# Proyección de ley IA y seguros

Instalar: `pip install -r requirements.txt`

Ejecutar: `streamlit run app.py`

Seleccionar las siete letras ganadoras en la barra lateral. Para proyectar, ocultar la barra lateral y usar F11. El Word se descarga cuando las siete alternativas están seleccionadas. Las selecciones se pueden conservar en la URL al pulsar «Actualizar texto aprobado».

Para publicar en Streamlit Community Cloud, subir estos tres archivos a un repositorio de GitHub y seleccionar `app.py`.
